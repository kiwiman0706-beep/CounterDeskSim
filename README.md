# CounterDeskSim

2F受付カウンター詳細図（1/20）をもとにした、診療所受付カウンターの3Dシミュレーション（横幅 1415mm）。

- `index.html` … ブラウザでそのまま開ける単体HTML（Three.js を CDN から読み込み）
- `counter.html` … 同じ内容の本文（Artifact 公開用）

## 機能
- マウス／タッチで回転・移動・拡大
- 視点プリセット（斜め・患者側・スタッフ側・側面・上から・座った目線）
- 設計案（当初案・変更案）の切り替えと、もう一方の案の輪郭線重ね表示、比較表
- 寸法線、人物（スケール確認）、間接照明、夜間モード、断面カット
- 横幅の変更（900〜3000mm）、木目・机・クロスの色替え
- 3D画面の下に平面図と設置機器の寸法表（XE-A20 本体の高さとドロアは推定値）
- 受付機器の配置と配置チェック（干渉・はみ出し・座った目線でのモニター隠れ）
  - スタッフ側壁: モバイルモニター ×4（Pisichen 16型、14／13.3型と比較可）
  - 机上: キーボード・マウス ×2、SHARP XE-A20 本体、UA-P10NA 店舗側、PRP-250、JD-SF3CL 子機 ×2
  - 机下: キャッシュドロア、ThinkCentre M75q Tiny Gen 5 ×2、HP Elite Mini 805 G8（マイナ受付用）（いずれもアンダーマウント）
  - カウンター上: マイナンバーカードリーダー、UA-P10NA 顧客側

## 寸法（図面より）
2つの設計案を切り替え・重ね表示で比較できます（初期表示は変更案）。

|---|---|---|
| カウンター高さ | 1100 | 1200 |
| 奥行 | 710（220＋490） | 910（550＋360） |
| 机の高さ | 680 | 700 |
| 机上〜天板下 | 390 | 470 |
